03guardrails

Guardrails sit outside the model.

bin/hooks/lead-gate.mjs, the PreToolUse hook on every tool call
leadBashgit push origin soma/fix-login-bugdeny
soma: leads may not push or merge through the shell. Hand it to a teammate.
teammateBashecho '{}' > .claude/settings.local.jsondeny
soma: .claude/settings.local.json is the file that keeps the operator's credentials — their MCP servers, database connections and authenticated connectors — out of reach of unattended agents. Rewriting it is never a step in a task. If you need a tool it denies, ask the orchestrator to allow it.
teammateMCPmcp__soma__soma_adoptdeny
soma: the soma bus belongs to the lead session. A teammate reaching it through user scope gets the CANDIDATE tool set, which carries soma_adopt — it could take the orchestrator lease out from under the operator. Report through the lead: finish your work, and the lead files soma_report.

04budgets and the watchdog

A breaker on every lead. A watchdog every 30 s.

sandboxed demo shell · lead-gate.mjs after a budget trip
$
the file the watchdog writes when a lead spends 100 % of its class
lead Bash npm test deny
soma: this task's budget is spent (BUDGET_TRIPPED). You may still talk and call soma_report — wind down now and file COMPLETED or ERROR with what exists. Ask the orchestrator to clear the trip if you need more.
teammate Edit deny same reason: teammates are bound by the same breaker
lead mcp__soma__soma_report allowed so it can still report and wind down
soma-watchdog.mjs, each tick
every 30 sone snapshot, eight pure decision functions
admitmax_leads (default 10), one per tick, 90 s stagger
reviveresume first; 3 attempts, then GAVE_UP
meterBUDGET event at 80 %; BUDGET_TRIPPED at 100 %
rotatea usage limit closes the lead's seat and moves it to the next open one; cross-seat resume not yet proven by a real rotation (RUNBOOK §10)
backpressurethe org spend cap freezes admission until soma thaw
pane censusflags dialogs and bare shells in lead panes
